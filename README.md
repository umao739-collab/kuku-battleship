# 九九せんすいかんバトル

九九の答えをこたえて、かくれた潜水艦をうちしずめる、小学生向けの対戦ゲームです。
Chromebook・タブレットのブラウザで遊べます（インストール不要）。

## あそびかた
- **ひとりで**：コンピュータと対戦します（強さは3段階）。
- **ふたりで**：同じタブレットをこうたいで使って対戦します。
  - はじめに、ひとりずつ相手に見えないように潜水艦をかくします。
  - そのあとは、同じ画面をふたりで見ながら対戦します。
- 相手の海のマスをタップして、そのマスの九九の答えを入れるとこうげきできます。
- あたったら、もう一回こうげきできます（神経衰弱と同じ方式）。
- コンピュータの番では、コンピュータがえらんだマスの九九にこたえます。まちがえても、せいかいするまでやり直せます。せいかいすると、こうげきがとどきます。
- 九九表は、左の数が「かけられる数」、上の数が「かける数」です。式の上に、九九の読み方（ひらがな）も出ます。
- 先に相手の潜水艦5隻（2・3・3・4・5マス）をぜんぶ沈めたら勝ちです。

## 作りかた
`index.html` 1ファイルだけで動きます（HTML・CSS・JavaScript）。
フォントは Google Fonts（M PLUS Rounded 1c）を読み込みます。読み込めない環境では標準フォントになります。
